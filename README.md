# Mapping

Mapping is a module for Omeka S that allows you to geolocate Omeka S items and
add interactive maps to your sites and pages.

It does this by adding new metadata fields to each item, a "Mapping" tab to item editing, and several batch-editing options for items. 

It can include location-based search fields on the advanced search forms on the admin and public interfaces.

It adds multiple page block options to Site Pages that can display maps and timelines for browsing items.

It adds a "Map Browse" page for each site, found in the Site Navigation settings.
    
It adds resource blocks to items and item sets (not media). Item sets can display maps that contain all of their items. 

Maps can display a variety of base maps, can have custom overlays added, and can have pins and shapes added that are not linked to items.

- [Omeka S developer documentation](https://omeka.org/s/docs/developer/module_docs/Mapping/)
